# Игра про шарики

Интерактивная игра с физикой шариков, смешиванием цветов и управлением через мышь.

## Описание игры

Это игра, в которой шарики движутся по экрану, сталкиваются друг с другом и смешивают свои цвета при касании. Игрок может управлять шариками с помощью мыши: всасывать их в инвентарь и выплёвывать обратно на экран.

### Основные возможности:

- **Движение шариков**: Шарики автоматически движутся по экрану и отскакивают от границ
- **Смешивание цветов**: При касании двух шариков их цвета смешиваются по улучшенной формуле, сохраняющей яркость
- **Всасывание шариков**: Зажмите левую кнопку мыши, чтобы всасывать шарики в инвентарь
- **Выплёвывание шариков**: Кликните правой кнопкой мыши, чтобы выплёвывать шарики из инвентаря
- **Зона удаления**: Правая нижняя часть экрана - специальная зона для удаления шариков
- **Инвентарь**: В левом верхнем углу отображается инвентарь с миниатюрами шариков

### Управление:

- **Левая кнопка мыши (ЛКМ)**: Всасывать шарики в инвентарь
- **Правая кнопка мыши (ПКМ)**: Выплёвывать шарик из инвентаря
- **Пробел**: Добавить новый случайный шарик на экран
- **C**: Очистить все шарики с экрана и из инвентаря
- **D**: Показать/скрыть зону удаления

## Локальный запуск

### Требования

- Python 3.7 или выше
- pip (менеджер пакетов Python)

### Зависимости

Игра использует следующие зависимости:
- `pygame>=2.5.0` - библиотека для создания графического интерфейса

### Установка и запуск

1. **Клонируйте репозиторий или скачайте файлы проекта**

2. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

   Или используйте:
   ```bash
   python -m pip install -r requirements.txt
   ```

3. **Запустите игру:**

   ```bash
   python gui.py
   ```

   Игра откроется в новом окне размером 1200x800 пикселей.

## Запуск в Docker-контейнере

Для запуска игры в Docker-контейнере с графическим интерфейсом используется X11 forwarding.

### Требования для Docker

- Docker установлен и запущен
- X11 сервер (для Linux) или XQuartz (для macOS) или Xming/VcXsrv (для Windows)

### Сборка и запуск Docker-контейнера

#### Linux

1. **Разрешите X11 forwarding:**

   ```bash
   xhost +local:docker
   ```

2. **Соберите Docker-образ:**

   ```bash
   docker build -t ball-game .
   ```

3. **Запустите контейнер:**

   ```bash
   docker run -it --rm \
     -e DISPLAY=$DISPLAY \
     -v /tmp/.X11-unix:/tmp/.X11-unix \
     --device=/dev/dri \
     ball-game
   ```

#### macOS

1. **Установите XQuartz** (если ещё не установлен):
   - Скачайте с https://www.xquartz.org/
   - Перезапустите компьютер после установки

2. **Настройте XQuartz:**
   - Откройте XQuartz Preferences → Security
   - Включите "Allow connections from network clients"
   - Перезапустите XQuartz

3. **Соберите Docker-образ:**

   ```bash
   docker build -t ball-game .
   ```

4. **Запустите контейнер:**

   ```bash
   IP=$(ifconfig en0 | grep inet | awk '$1=="inet" {print $2}')
   xhost + $IP
   docker run -it --rm \
     -e DISPLAY=$IP:0 \
     ball-game
   ```

#### Windows

1. **Установите VcXsrv или Xming:**
   - VcXsrv: https://sourceforge.net/projects/vcxsrv/
   - Xming: https://sourceforge.net/projects/xming/

2. **Запустите X-сервер:**
   - В настройках включите "Disable access control"
   - Запомните IP-адрес вашего компьютера (можно узнать через `ipconfig`)

3. **Соберите Docker-образ:**

   ```powershell
   docker build -t ball-game .
   ```

4. **Запустите контейнер:**

   ```powershell
   docker run -it --rm `
     -e DISPLAY=YOUR_IP:0 `
     ball-game
   ```

   Замените `YOUR_IP` на IP-адрес вашего компьютера (например, `192.168.1.100:0`)

### Альтернативный способ (проще для Windows)

Если у вас установлен WSL2 с Docker Desktop:

1. **В WSL2 выполните:**

   ```bash
   export DISPLAY=$(cat /etc/resolv.conf | grep nameserver | awk '{print $2}'):0
   docker build -t ball-game .
   docker run -it --rm -e DISPLAY=$DISPLAY ball-game
   ```

## Технические детали

### Смешивание цветов

Игра использует улучшенную формулу смешивания цветов, основанную на математическом подходе:
- Формула: `sqrt((color1² + color2²) / 2)`
- Эта формула сохраняет яркость при смешивании, предотвращая затемнение
- Учитывает, что RGB - аддитивная цветовая модель (свет)

### Производительность

- Игра работает с частотой 60 FPS
- Оптимизирована для плавной анимации
- Поддерживает до нескольких десятков шариков одновременно
